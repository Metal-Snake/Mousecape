# Where to find cursors

Places to get cursor themes for Mousecape. None of these are part of this project: check
each theme's licence before you share or change it, and only download from sources you
trust. Mousecape imports four kinds of files:

- **Capes** (`.cape`): open them, drag them onto the window, or use File → Import.
- **Windows cursors** (`.cur`, `.ani`): import a theme folder, its `install.inf`, an
  archive of it, or single files.
- **Linux cursors** (Xcursor, files without extension): import a theme folder, an archive
  of it, or single files.
- **MightyMouse** (`.MightyMouse`): converted on import.

Archives can be `.zip`, `.7z`, `.rar`, `.tar`, `.tar.gz`, `.tar.bz2` or `.tar.xz`; only
`.tar.zst` has to be unpacked first.

## Linux cursors (Xcursor)

Themes for Linux desktops, usually as `.tar.xz` or `.tar.gz`. Most of the Windows themes
above come from Linux and have a Linux package too, with sharper images and more cursors.

| Link | What | Notes |
|---|---|---|
| [ful1e5/Bibata_Cursor](https://github.com/ful1e5/Bibata_Cursor/releases) | Bibata, many colours | `Bibata-*.tar.xz`. GPL-3.0 |
| [ful1e5/apple_cursor](https://github.com/ful1e5/apple_cursor/releases) | macOS look-alike | `macOS.tar.xz`, `macOS-White.tar.xz`. GPL-3.0 |
| [ful1e5/BreezeX_Cursor](https://github.com/ful1e5/BreezeX_Cursor/releases) | BreezeX | GPL-3.0 |
| [ful1e5/Google_Cursor](https://github.com/ful1e5/Google_Cursor/releases) | GoogleDot | GPL-3.0 |
| [ful1e5/banana-cursor](https://github.com/ful1e5/banana-cursor/releases) | A banana | `banana-all.tar.xz` holds several themes; Mousecape imports the first |
| [gnome-look.org: Cursors](https://www.gnome-look.org/browse?cat=107) | Thousands of themes (the same catalogue as pling.com and store.kde.org) | Mixed quality and licences |

## MightyMouse

MightyMouse was a cursor tool by Unsanity for Mac OS X 10.3–10.5; the company is gone and
so are most `.MightyMouse` files.

| Link | What | Notes |
|---|---|---|
| [Macintosh Repository: Mighty Mouse](https://www.macintoshrepository.org/33199-mighty-mouse) | The app's disk images plus `Mighty_Mouse_Cursors.zip` (8.8 MB) and `More_Cursors.zip` | Archive of the original downloads; the only source for cursor sets found so far |

Themes that are useful for testing Mousecape are listed in [TESTING.md](TESTING.md#test-themes).
